# ArzanAccount Frontend (Next.js 14 + Tailwind CSS + Stitch UI)

فرانت‌اند مدرن و سریع فروشگاه دیجیتال **ارزان اکانت** با فریم‌ورک **Next.js 14 App Router**، طراحی پالت رنگی هماهنگ، بهینه‌سازی کامل سئو (SEO) و پنل کنترل سنتر پیشرفته ادمین (**HypeStore Admin Theme**).

---

## قابلیت‌های کلیدی (Core Features)

- **فروشگاه و ویترین محصولات:**
  - نمایش کاتالوگ جامع محصولات و سرویس‌های دیجیتال (ChatGPT، Spotify، Telegram Premium و ...).
  - صفحه اختصاصی جزییات محصول همراه با انتخاب پلن و تحویل آنی.
  - سبد خرید تعاملی، سیستم محاسبه خودکار قیمت بر اساس نرخ دلار و کد تخفیف.
  - پیگیری سفارش و استعلام لایسنس دیجیتال.
- **احراز هویت و سطوح دسترسی (Auth & RBAC):**
  - مودال و صفحه لاگین با کد یکبارمصرف (OTP) متصل به بک‌اند.
  - احراز هویت با JWT Token و اعتبارسنجی زنده سشن کاربر.
  - گارد امنیتی چندسطحی در کنترل سنتر (`/admin`) با خطای ۴۰۳ برای کاربران عادی.
  - سایدبار هوشمند و فیلتر خودکار منوها بر اساس نقش مدیر لاگین‌شده.
- **کنترل سنتر جامع مدیریت (HypeStore Admin):**
  - داشبورد آمار، سفارشات در حال پردازش و سود کل.
  - مدیریت و ویرایش پیشرفته محصولات (عنوان اختصاصی، تصاویر، وضعیت، قیمت دلاری و تومانی).
  - مدیریت سفارشات، لایسنس‌ها، موجودی انبار و دسته‌بندی‌ها.
  - مدیریت پرسنل و سطوح دسترسی کاربران (`/admin/users`).
  - تنظیمات نرخ ارز مرجع، تخفیف‌ها، لاگ سیستم و هوش تجاری.
- **سئو و بهینه‌سازی (SEO & Performance):**
  - تولید خودکار `sitemap.xml` و `robots.txt`.
  - ساختار داده‌ای استاندارد Schema.org (`JsonLd`).
  - رندر استاتیک و هایبرید برای سرعت بارگذاری فوق‌العاده.

## راه‌اندازی سریع (Getting Started)

### ۱. نصب وابستگی‌ها
```bash
npm install
```

### ۲. اجرای پروژه در محیط توسعه
```bash
npm run dev
```
سایت بر روی آدرس `http://localhost:3000` در دسترس خواهد بود.

### ۳. بیلد پروژه
```bash
npm run build
npm start
```
